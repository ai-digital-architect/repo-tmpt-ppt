# Education, Food & Travel Templates

## Overview
Templates designed for academic presentations, food industry statistics, travel itineraries, and lifestyle-focused presentations.

## Use Cases
- Educational presentations and lectures
- Course materials and syllabi
- Food industry reports and menus
- Travel itineraries and guides
- Recipe presentations
- Destination comparisons

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `education-course-syllabus.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Update content for your specific topic
3. Replace placeholder images with relevant visuals
4. Adjust layouts for your content length
5. Customize colors to match institution/brand

### 3. Design Tips - Education
- Use clear headings and subheadings
- Include learning objectives
- Use bullet points for key concepts
- Add diagrams for complex topics
- Include references and citations

### 4. Design Tips - Food
- Use high-quality food photography
- Include ingredient lists clearly
- Show nutritional information if relevant
- Use appetizing color schemes
- Include preparation steps visually

### 5. Design Tips - Travel
- Include destination photos and maps
- Show itinerary in timeline format
- List activities and points of interest
- Include practical information (costs, times, locations)
- Use icons for different activity types

### 6. Export
- Save as .pptx for classroom/presentation use
- Export as PDF for handouts and distribution
- Use PNG for online sharing (blogs, websites)

## Template Naming Convention
Use the format: `[industry]-[type]-[topic].pptx`
- Examples: `education-lecture-biology.pptx`, `food-menu-restaurant.pptx`, `travel-itinerary-europe.pptx`

## Best Practices
- Use large, readable fonts (min 24pt for presentations)
- Include interactive elements for engagement
- Use consistent formatting throughout
- Include contact information for follow-ups
- Add QR codes for additional resources
- Keep text minimal, focus on visuals
