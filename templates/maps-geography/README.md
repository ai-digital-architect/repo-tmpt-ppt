# Maps & Geography Templates

## Overview
Templates featuring world maps, regional maps, location-based data visualization, and geographical presentations. Perfect for global business, travel, and location-based analytics.

## Use Cases
- Global expansion presentations
- Regional sales and distribution
- Travel destinations and routes
- Demographic data visualization
- Market presence mapping
- Office/store location displays
- Geographic analysis

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `world-map-sales-regions.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Highlight relevant regions or countries
3. Add markers for specific locations
4. Update data labels and statistics
5. Customize colors by region or metric
6. Add legend for color coding

### 3. Design Tips
- Use color intensity for data values (heat maps)
- Add pins or markers for specific locations
- Include zoom-in insets for detailed areas
- Use consistent color schemes across slides
- Add country/region labels clearly
- Include scale or distance indicators when relevant

### 4. Map Template Types
- **World Maps**: Global view with country boundaries
- **Regional Maps**: Continents or specific regions
- **Country Maps**: Individual country with states/provinces
- **City Maps**: Urban areas with landmarks
- **Heat Maps**: Data intensity visualization
- **Route Maps**: Travel paths and connections

### 5. Data Visualization on Maps
- Use bubble size for quantities
- Use color gradients for ranges
- Add arrows for flows or movements
- Include data callouts for key locations
- Show comparisons with side-by-side maps

### 6. Export
- Save as .pptx for presentations
- Export as PDF for reports
- Use high-resolution PNG for posters
- Export as SVG for web use

## Template Naming Convention
Use the format: `map-[region]-[purpose].pptx`
- Examples: `map-world-sales.pptx`, `map-usa-offices.pptx`, `map-europe-expansion.pptx`

## Best Practices
- Ensure map accuracy and current borders
- Use politically neutral colors
- Include data sources for statistics
- Make maps accessible (avoid color-only coding)
- Use appropriate projections for the region
- Test readability of labels
- Include a legend or key
- Consider time zones for global maps
