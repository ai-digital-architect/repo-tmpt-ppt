# Milestones, Goals & KPI Templates

## Overview
Templates for tracking progress, highlighting key performance indicators, displaying achieved targets, and goal management presentations.

## Use Cases
- KPI dashboards and scorecards
- Goal setting and tracking (OKRs, SMART goals)
- Milestone achievement presentations
- Performance reviews
- Target vs. actual comparisons
- Progress tracking

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `kpi-dashboard-monthly.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Update KPI metrics with current values
3. Add target values and actual performance
4. Adjust progress bars and indicators
5. Customize colors for status (red/yellow/green)
6. Update time periods and dates

### 3. KPI Best Practices
- Focus on 3-7 key metrics per view
- Use actual numbers, not just percentages
- Include comparison context (target, previous period)
- Show trends with mini charts (sparklines)
- Use clear units and labels
- Update regularly (daily, weekly, monthly)

### 4. Goal Template Types
- **OKRs**: Objectives and Key Results framework
- **SMART Goals**: Specific, Measurable, Achievable, Relevant, Time-bound
- **Balanced Scorecard**: Financial, Customer, Process, Learning perspectives
- **KPI Dashboards**: Real-time performance monitoring
- **Progress Trackers**: Visual completion status

### 5. Design Tips
- Use gauges for single metrics (0-100%)
- Progress bars for goal completion
- Traffic light colors for status (🔴🟡🟢)
- Include trend arrows (↑↓→)
- Show year-over-year or period-over-period comparisons
- Highlight achievements prominently

### 6. Export
- Save as .pptx for business reviews
- Export as PDF for stakeholder reports
- Use PNG for dashboards and monitoring displays

## Template Naming Convention
Use the format: `[type]-[frequency/purpose].pptx`
- Examples: `kpi-dashboard-weekly.pptx`, `goals-okr-quarterly.pptx`, `milestones-project.pptx`

## Best Practices
- Define KPIs clearly before tracking
- Ensure metrics are actionable
- Use leading and lagging indicators
- Align KPIs with strategic goals
- Review and adjust goals periodically
- Celebrate achieved milestones
- Include accountability (owner names)
- Add brief analysis or insights
