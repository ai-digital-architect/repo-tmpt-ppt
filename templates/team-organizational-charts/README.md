# Team & Organizational Charts Templates

## Overview
Templates for visualizing team structures, HR layouts, mind maps, and organizational hierarchies. Perfect for org structure presentations and team introductions.

## Use Cases
- Organizational hierarchy charts
- Team structure diagrams
- Mind maps and brainstorming
- Department layouts
- Reporting relationships
- Skills and capabilities matrices

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `org-chart-hierarchical.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Replace placeholder names with actual team members
3. Update titles and roles
4. Adjust hierarchy levels as needed
5. Add photos or avatars if desired
6. Customize colors by department or function

### 3. Design Tips
- Use consistent box sizes for same-level positions
- Include contact information if appropriate
- Use photos for team presentations
- Color-code by department or location
- Show dotted lines for matrix reporting

### 4. Template Types
- **Hierarchical Charts**: Traditional top-down structures
- **Matrix Organizations**: Multiple reporting lines
- **Flat Organizations**: Minimal hierarchy
- **Mind Maps**: Idea organization and brainstorming
- **Team Rosters**: Names, roles, and contact info

### 5. Export
- Save as .pptx for HR and leadership updates
- Export as PDF for all-hands distributions
- Use PNG for intranet or documentation

## Template Naming Convention
Use the format: `[type]-[structure].pptx`
- Examples: `orgchart-hierarchical.pptx`, `mindmap-central-branches.pptx`

## Best Practices
- Update regularly as team changes occur
- Include legends for color codes
- Keep names and titles current
- Use appropriate font sizes (min 14pt)
- Consider privacy when sharing externally
- Show reporting relationships clearly
