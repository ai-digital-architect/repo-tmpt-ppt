# SWOT Analysis & Decision Trees Templates

## Overview
Templates for strategic planning, SWOT analysis, risk assessment, and decision-making visualizations. Essential for business strategy and analytical presentations.

## Use Cases
- SWOT analysis (Strengths, Weaknesses, Opportunities, Threats)
- Decision tree diagrams
- Risk assessment matrices
- Strategic planning sessions
- Problem-solving frameworks
- Scenario analysis

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `swot-analysis-quadrant.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Fill in SWOT quadrants with relevant points
3. Update decision tree branches with options
4. Add probabilities or impact scores
5. Customize colors to show positive/negative factors

### 3. SWOT Analysis Tips
- **Strengths**: Internal positive attributes
- **Weaknesses**: Internal limitations
- **Opportunities**: External favorable conditions
- **Threats**: External challenges
- Aim for 3-5 items per quadrant
- Be specific and actionable
- Use data to support points

### 4. Decision Tree Tips
- Start with the main decision at root
- Branch out with possible options
- Include probabilities if known
- Show outcomes at end nodes
- Use colors to highlight recommended path
- Include decision criteria

### 5. Risk Matrix Elements
- Plot risks by likelihood and impact
- Use color coding (red/yellow/green)
- Include mitigation strategies
- Prioritize high-impact, high-probability risks
- Review and update regularly

### 6. Export
- Save as .pptx for strategy workshops
- Export as PDF for documentation
- Use PNG for reports and presentations

## Template Naming Convention
Use the format: `[type]-[variant].pptx`
- Examples: `swot-quadrant-classic.pptx`, `decision-tree-3options.pptx`, `risk-matrix-2x2.pptx`

## Best Practices
- Be honest and objective in SWOT
- Involve stakeholders in the process
- Link analysis to actionable strategies
- Update SWOT regularly (quarterly/annually)
- Use consistent criteria for evaluation
- Document assumptions for decision trees
- Show clear recommendation or next steps
