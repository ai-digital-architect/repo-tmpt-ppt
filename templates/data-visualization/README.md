# Data Visualization Templates

## Overview
Advanced templates for comprehensive data visualization, infographics, and complex data storytelling. Combines multiple chart types and visual elements.

## Use Cases
- Executive dashboards
- Annual reports
- Research presentations
- Data storytelling
- Infographic presentations
- Complex data analysis
- Business intelligence

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `dashboard-executive-summary.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Replace placeholder data with actual metrics
3. Update multiple chart types as needed
4. Adjust layouts for your data story
5. Customize colors for data categories
6. Add annotations and insights

### 3. Data Storytelling Tips
- Start with the key message or insight
- Use progressive disclosure (build complexity)
- Combine multiple visualizations for context
- Guide viewers through the data journey
- End with clear conclusions or recommendations

### 4. Template Types
- **Executive Dashboards**: High-level KPIs and trends
- **Infographics**: Visual data storytelling
- **Research Findings**: Study results and analysis
- **Comparison Viz**: Multi-dimensional comparisons
- **Trend Analysis**: Time-series and patterns
- **Interactive Dashboards**: Click-through data exploration

### 5. Design Principles
- **Clarity**: Easy to understand at a glance
- **Accuracy**: Truthful representation of data
- **Efficiency**: Minimal ink for maximum insight
- **Aesthetics**: Visually appealing and professional
- **Hierarchy**: Emphasize important information

### 6. Color Guidelines
- Use consistent color palette throughout
- Reserve bright colors for highlights
- Use neutral colors for less important data
- Ensure sufficient contrast
- Consider color-blind accessibility
- Match brand colors when appropriate

### 7. Export
- Save as .pptx for interactive viewing
- Export as PDF for distribution
- Use high-resolution PNG for publications
- Export individual viz as images

## Template Naming Convention
Use the format: `dataViz-[type]-[purpose].pptx`
- Examples: `dataViz-dashboard-executive.pptx`, `dataViz-infographic-annual.pptx`

## Best Practices
- Less is more - avoid chart junk
- Label everything clearly
- Use consistent units and scales
- Include data sources and timestamps
- Test comprehension with others
- Use white space effectively
- Align elements for clean layout
- Consider animation for progressive reveal
- Add context and insights, not just raw data
