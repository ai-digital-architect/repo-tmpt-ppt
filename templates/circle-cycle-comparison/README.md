# Circle, Cycle & Comparison Templates

## Overview
Templates featuring circular diagrams, cycles, Venn diagrams, and comparison layouts for analyzing similarities, differences, and continuous processes.

## Use Cases
- Process cycles and iterations
- Venn diagram comparisons
- Before/after comparisons
- Product/service comparisons
- Continuous improvement cycles
- Circular workflows

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `venn-3circle-comparison.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Update cycle stages or comparison categories
3. Adjust number of elements in circular diagrams
4. Customize overlapping areas in Venn diagrams
5. Update comparison criteria and details

### 3. Design Tips
- Use clockwise flow for cycle diagrams
- Show relationships in Venn diagram overlaps
- Use contrasting colors for comparison
- Include arrows to show direction of flow
- Keep text balanced across sections

### 4. Template Types
- **Cycle Diagrams**: Continuous or repeating processes
- **Venn Diagrams**: Set overlaps and relationships
- **Comparison Tables**: Side-by-side feature comparison
- **Circular Flows**: Closed-loop processes
- **Before/After**: Change impact visualization

### 5. Export
- Save as .pptx for collaborative editing
- Export as PDF for reports
- Use SVG or high-res PNG for web use

## Template Naming Convention
Use the format: `[type]-[elements].pptx`
- Examples: `cycle-4stages.pptx`, `venn-3circles.pptx`, `comparison-table-2col.pptx`

## Best Practices
- Keep cycles to 3-7 stages for clarity
- Use consistent segment sizes in circles (unless showing proportions)
- Highlight key overlaps in Venn diagrams
- Use neutral colors for balanced comparisons
- Include a summary or conclusion slide
