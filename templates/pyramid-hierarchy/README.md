# Pyramid & Hierarchy Templates

## Overview
Templates for pyramid charts, iceberg models, Maslow's hierarchy, and other hierarchical visualizations. Perfect for showing ranking, priorities, and layered concepts.

## Use Cases
- Hierarchical information display
- Priority rankings
- Maslow's hierarchy of needs
- Food pyramids
- Organizational levels
- Iceberg models (visible vs. hidden)
- Funnel alternatives

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `pyramid-5levels-priorities.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Update each pyramid level with your content
3. Adjust the number of levels (typically 3-7)
4. Customize colors to show progression or importance
5. Add icons or symbols for each level

### 3. Design Tips - Pyramid
- Place most important/foundational at base
- Show progression from bottom to top
- Use consistent width changes between levels
- Include percentages or proportions if relevant
- Label each level clearly

### 4. Design Tips - Iceberg
- Use waterline to separate visible/hidden
- Show smaller portion above water (visible)
- Show larger portion below (hidden factors)
- Great for root cause analysis
- Useful for showing underlying issues

### 5. Common Pyramid Types
- **Priority Pyramid**: Rankings from critical to nice-to-have
- **Skills Pyramid**: From fundamental to advanced
- **Market Pyramid**: From mass market to niche
- **Learning Pyramid**: Different learning methods and retention
- **Needs Hierarchy**: Basic needs to self-actualization

### 6. Export
- Save as .pptx for team discussions
- Export as PDF for reports
- Use SVG for scalable graphics

## Template Naming Convention
Use the format: `[type]-[levels]-[purpose].pptx`
- Examples: `pyramid-5levels-priorities.pptx`, `iceberg-root-cause.pptx`

## Best Practices
- Keep to 3-7 levels for clarity
- Ensure logical ordering (foundation to peak)
- Use size to represent importance or volume
- Include brief descriptions for each level
- Consider using percentages for proportional pyramids
- Use warm colors at top, cool at base (or vice versa for emphasis)
