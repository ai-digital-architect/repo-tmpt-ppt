# Charts & Statistics Templates

## Overview
Templates for bar charts, pie charts, data dashboards, and statistical infographics. Essential for representing numbers, metrics, and trends effectively.

## Use Cases
- Data visualization and analytics
- Performance dashboards
- Survey results presentation
- Statistical analysis
- Business intelligence reports
- KPI tracking

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `dashboard-kpi-executive.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Update chart data with your actual values
3. Adjust chart types as needed (bar, line, pie, scatter)
4. Customize colors to match data categories
5. Update labels, legends, and titles

### 3. Chart Selection Guide
- **Bar Charts**: Compare values across categories
- **Line Charts**: Show trends over time
- **Pie Charts**: Display parts of a whole (use for 3-6 segments max)
- **Scatter Plots**: Show correlation between variables
- **Area Charts**: Emphasize magnitude of change over time
- **Combo Charts**: Multiple metrics with different scales

### 4. Design Tips
- Choose appropriate chart type for your data
- Use consistent color schemes
- Include clear axis labels and units
- Add data labels for key values
- Use gridlines sparingly
- Highlight important data points

### 5. Data Dashboard Best Practices
- Group related metrics together
- Use big numbers for key metrics
- Include trend indicators (↑↓)
- Show context (vs. previous period, target, benchmark)
- Use sparklines for quick trend views

### 6. Export
- Save as .pptx for interactive presentations
- Export as PDF for reports
- Use high-resolution PNG for documentation
- Export data to Excel if needed

## Template Naming Convention
Use the format: `[chart-type]-[purpose].pptx`
- Examples: `dashboard-sales-monthly.pptx`, `barchart-comparison.pptx`, `piechart-market-share.pptx`

## Best Practices
- Always include data sources
- Use accurate scales (don't manipulate to mislead)
- Keep charts simple and focused
- Limit to 3-4 data series per chart
- Test readability from distance
- Use color-blind friendly palettes
- Add brief insights or conclusions
