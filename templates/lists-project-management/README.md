# Lists & Project Management Templates

## Overview
Templates for checklists, to-do lists, task tracking, Gantt charts, and project overviews. Essential for project managers and team coordination.

## Use Cases
- Project task lists and checklists
- Gantt charts and timelines
- Resource allocation
- Sprint planning
- Task prioritization
- Project status dashboards

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `gantt-chart-monthly.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Update task lists with your project tasks
3. Adjust Gantt chart timelines and durations
4. Assign resources or team members
5. Update status indicators and progress bars

### 3. Design Tips
- Use checkbox symbols for completion status
- Color-code by priority or task category
- Include responsible party for each task
- Show dependencies in Gantt charts
- Use progress bars for visual status updates

### 4. Template Types
- **Gantt Charts**: Timeline-based project schedules
- **Task Lists**: Prioritized action items
- **Kanban Boards**: Visual task flow management
- **Resource Planning**: Team allocation and capacity
- **Milestone Tracking**: Key deliverable monitoring

### 5. Export
- Save as .pptx for updates in project meetings
- Export as PDF for status reports
- Share via cloud for collaborative editing

## Template Naming Convention
Use the format: `[type]-[variant].pptx`
- Examples: `gantt-monthly.pptx`, `tasklist-priority-matrix.pptx`

## Best Practices
- Update regularly to reflect current status
- Use RAG (Red/Amber/Green) status indicators
- Keep task descriptions actionable and specific
- Include target dates and actual completion dates
- Highlight blockers and risks prominently
