# Timeline Templates

## Overview
Timeline templates are used to showcase events, milestones, or project phases in chronological order. Perfect for project planning, historical presentations, and milestone tracking.

## Use Cases
- Project timelines and milestones
- Historical event sequences
- Product roadmap timelines
- Company history presentations
- Process evolution over time

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `project-timeline-horizontal.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Replace placeholder text with your content
3. Adjust timeline dates and milestones
4. Customize colors to match your brand (all elements are fully editable)
5. Add or remove timeline nodes as needed

### 3. Design Tips
- Keep timeline entries concise and scannable
- Use consistent icon styles throughout
- Maintain chronological order (left-to-right or top-to-bottom)
- Use color coding to differentiate phases or categories
- Include key dates prominently

### 4. Export
- Save as .pptx for further editing
- Export as PDF for sharing
- Export individual slides as images if needed

## Template Naming Convention
Use the following format: `timeline-[type]-[orientation].pptx`
- Examples: `timeline-project-horizontal.pptx`, `timeline-history-vertical.pptx`

## Best Practices
- Limit to 5-10 major milestones per slide for readability
- Use icons to make milestones visually distinctive
- Test readability on projector or smaller screens
- Keep font sizes minimum 18pt for body text
