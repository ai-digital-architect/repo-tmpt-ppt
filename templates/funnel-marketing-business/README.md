# Funnel, Marketing & Business Templates

## Overview
Templates for sales and marketing funnels, SWOT analysis, value chains, and marketing plans. Essential for business strategy and marketing presentations.

## Use Cases
- Sales funnel visualization
- Marketing campaign planning
- Conversion rate analysis
- Customer journey mapping
- Business model presentations
- Value proposition design

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `sales-funnel-conversion.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Update funnel stages with your sales/marketing process
3. Add metrics and conversion rates at each stage
4. Customize colors to match your brand
5. Include call-to-action or next steps

### 3. Design Tips
- Show volume/numbers decreasing through funnel
- Use percentages to highlight conversion rates
- Include key metrics at each stage
- Use consistent color schemes for each funnel level
- Add icons for quick visual recognition

### 4. Template Types
- **Sales Funnels**: Lead to customer conversion
- **Marketing Funnels**: Awareness to purchase journey
- **SWOT Analysis**: Strengths, Weaknesses, Opportunities, Threats
- **Business Models**: Canvas, value chains, and frameworks
- **Marketing Mix**: 4Ps, 7Ps frameworks

### 5. Export
- Save as .pptx for internal strategy sessions
- Export as PDF for client presentations
- Use PNG for marketing collateral

## Template Naming Convention
Use the format: `[type]-[purpose].pptx`
- Examples: `funnel-sales-conversion.pptx`, `swot-analysis-template.pptx`

## Best Practices
- Include actual data/metrics when presenting
- Show before and after for improvement stories
- Use animations to reveal funnel stages progressively
- Compare funnels (e.g., current vs. target state)
- Highlight key insights and action items
