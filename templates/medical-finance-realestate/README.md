# Medical, Finance & Real Estate Templates

## Overview
Specialized templates for healthcare analytics, financial dashboards, real estate property overviews, and industry-specific presentations.

## Use Cases
- Healthcare dashboards and metrics
- Financial reports and statements
- Investment presentations
- Property listings and comparisons
- Medical research presentations
- Budget and forecasting

## Setup Instructions

### 1. Download Template
- Place your PowerPoint template files (.pptx) in this directory
- Use descriptive filenames (e.g., `financial-dashboard-quarterly.pptx`)

### 2. Customize Template
1. Open the template in Microsoft PowerPoint, Keynote, or Google Slides
2. Update data and metrics with current information
3. Replace placeholder charts with actual data
4. Customize branding and colors (maintain industry professionalism)
5. Update currency symbols and units as needed

### 3. Design Tips - Medical
- Use professional medical imagery
- Include disclaimers where appropriate
- Follow HIPAA guidelines for patient data
- Use clear data visualization for clinical results
- Include citation sources for research data

### 4. Design Tips - Finance
- Maintain professional color schemes (blues, greens, grays)
- Show trends with line charts
- Use tables for detailed numbers
- Include date ranges and comparative periods
- Add disclaimers and data sources

### 5. Design Tips - Real Estate
- Include high-quality property images
- Show key metrics (sq ft, price, location)
- Use maps for location context
- Include comparison properties
- Highlight unique selling points

### 6. Export
- Save as .pptx for internal reviews
- Export as PDF for client/patient sharing (ensure confidentiality)
- Use high-resolution images for property listings

## Template Naming Convention
Use the format: `[industry]-[type]-[purpose].pptx`
- Examples: `medical-dashboard-kpis.pptx`, `finance-report-quarterly.pptx`, `realestate-listing-residential.pptx`

## Best Practices
- Verify data accuracy before presenting
- Follow industry regulations (HIPAA, SEC, etc.)
- Use professional, industry-appropriate imagery
- Include proper disclaimers and disclosures
- Maintain consistency in units and formatting
- Protect sensitive information appropriately
