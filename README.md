# PowerPoint Template Repository

A comprehensive collection of professionally designed PowerPoint templates with strong visuals, organized by category. This repository is inspired by infograpia's extensive template library, featuring 14 major categories covering business, education, marketing, analytics, and more.

## 📁 Repository Structure

All templates are organized in the `templates/` directory by category:

```
templates/
├── timelines/                    # Timeline and milestone presentations
├── strategy-process-roadmap/     # Business strategy and process flows
├── lists-project-management/     # Task lists, Gantt charts, project tracking
├── funnel-marketing-business/    # Sales funnels, SWOT, marketing plans
├── circle-cycle-comparison/      # Cycles, Venn diagrams, comparisons
├── team-organizational-charts/   # Org charts, team structures, mind maps
├── medical-finance-realestate/   # Industry-specific templates
├── education-food-travel/        # Educational and lifestyle presentations
├── charts-statistics/            # Data visualization and dashboards
├── swot-decision-trees/          # Strategic analysis and decision making
├── pyramid-hierarchy/            # Hierarchical visualizations
├── milestones-goals-kpi/         # KPI tracking and goal management
├── maps-geography/               # Geographic data and location mapping
└── data-visualization/           # Advanced infographics and data stories
```

## 🚀 Quick Start

1. **Browse Categories**: Navigate to the category folder that matches your needs
2. **Read Instructions**: Each category has a detailed README.md with setup instructions
3. **Download Template**: Select and download the .pptx file you need
4. **Customize**: Open in PowerPoint, Keynote, or Google Slides and personalize
5. **Present**: Export as PDF or present directly

## 💡 Usage Guidelines

### Customization
1. All elements are fully editable - adjust to match your brand
2. Use consistent color schemes throughout your presentation
3. Replace placeholder text and images with your content
4. Maintain visual hierarchy for readability
5. Test on projector or presentation screen

### File Naming Convention
Follow this format when adding templates:
```
[category]-[type]-[variant].pptx
```
Examples:
- `timeline-project-horizontal.pptx`
- `dashboard-kpi-executive.pptx`
- `funnel-sales-conversion.pptx`

### Best Practices
- Keep font sizes readable (minimum 18pt for body, 24pt+ for presentations)
- Use high-contrast colors for accessibility
- Limit animations to enhance, not distract
- Include data sources and citations
- Test readability from audience perspective
- Export as PDF for final distribution
